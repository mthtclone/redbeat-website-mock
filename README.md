This repository contains mockup website where producers/artists can register and sell beats online. This project is uploaded for portfolio purposes.

This project was done for the final major assignment of the Ecommerce and Payment System class in ILC.

Documentation (Readbeat - Software Design Document.pdf) and Wireframe (Wireframes_FIGMA_EXPORT.pdf) are in the repository.

Note that this is not a fully functional website and the tech stack choice is deliberately toned down for easy production. In real life commerce site, frameworks like Vue and Reacts are much more commonly used with other languages as needed.
